Efficient long-video question answering

How should an Agent find the few moments that matter in a long video? My dissertation studies how organizing evidence before a question arrives changes the work needed to answer it.

01 / SYSTEM DESIGN

Build the map once. Inspect evidence when needed.

Starting from a broad research goal, I identified evidence localization and context handling as bottlenecks. I built a training-free semantic index that links event summaries to finer time intervals and source frames, so the same video representation can support different questions.

Staged
Separate planning, evidence investigation, optional frame review and final answering stages.
Direct
One answering Agent uses the map and can inspect source frames as needed.

02 / EVALUATION DESIGN

A manageable sample with balanced question types

The main evaluation used 300 visual, five-choice questions across 12 long videos from HourVideo. Under limited resources, I sampled questions in proportion to the source question-type distribution and used paired comparisons and input ablations to study answer quality, completion and resource use.

03 / EXPERIMENTAL FINDINGS

Where the savings come from—and where they stop

Retrieval strategy changes downstream work

I adapted VideoSEAL's retrieval backend to compare flat and hierarchical evidence access. At a nominal budget of 15, hierarchical retrieval reduced recorded processing time while retaining similar observed accuracy to Flat-30. The same advantage did not hold at budget 30.

The comparisons change both the index and retrieval procedure; similar accuracy does not establish statistical equivalence.

A richer index can reduce later processing

Local paired subset: R3 used 27.2% fewer online tokens across the full workflow, with 52 rather than 51 correct answers out of 150. More planning input was offset by less downstream processing.

Context limits matter: the other 150 R3 questions exceeded the local Planner's context capacity. This result therefore applies to the context-feasible subset.

Tokens and money are different measures: with an API Planner on all 300 questions, R3 used fewer total tokens but had a higher Planner API bill: $10.10 versus $4.97.

Additional stages need to justify their cost

Holding the semantic index and model fixed, I compared Direct answering with a Full Staged workflow on the same 100 questions. Direct used 70.3% less online API expenditure. The observed accuracy difference was not statistically significant.

04 / QUALITATIVE CASE STUDY

Speech changes what the map can tell you

A separate EgoPolice case compares visual-only and speech-enhanced maps of the same recording. Speech changes event organization and some frame-selection choices. It can supply context that is absent from images, but a spoken reference to an action does not establish that the action is visibly shown.
